# GOSTIN LED LAMP — v7.5.15 / Android v1.3.0

💚 **SMART LIGHT — автоматичне світло, яке реагує на звук і час доби.**

## Головне
- Вечірній і нічний режими з окремою яскравістю та колірною температурою **1800–6500 K**.
- **SMART REWIND:** при повторному звуці згасання відтворюється назад із поточного положення, без нового запуску з нуля.
- **Години тиші:** блокують нові запуски лише після повного OFF. Якщо лампа вже світить, звук продовжує таймер і реверс навіть у цей період.
- **Чотири світлові будильники:** розклад, наростання яскравості, індивідуальна колірна температура.
- Оновлена структура панелі SMART LIGHT, налаштування анімації під шестернею, прибрана кнопка тесту будильника.
- Web UI та Android підтримують однакові параметри.

## Файли релізу
- `LED-Lampa.apk` — застосунок Android 1.3.0.
- `esp-release.zip` — ESP firmware 7.5.15 та Web UI.
- `SHA256SUMS.txt` — контрольні суми.

**Увага:** перевір сумісність цих трьох файлів між собою. Встановлення поверх старого Android потребує APK, підписаного попереднім ключем. Нові години тиші, OTA та тривалу стабільність саме фінального комплекту ще слід перевірити на реальному пристрої.
