# GOSTIN LED LAMP — Android 1.3.0 / ESP8266 7.5.15

**SMART LIGHT:** автоматичне вечірнє й нічне освітлення за звуком, SMART ANIMATION і SMART REWIND.

- Яскравість і колірна температура **1800–6500 K** незалежно для вечора, ночі та будильників.
- Геолокація, час доби, сонячні події та DST.
- Години тиші блокують лише **новий запуск** із повного OFF; активний цикл може продовжуватися.
- Чотири незалежні світлові будильники.
- Оновлені Web UI та Android для налаштувань SMART LIGHT.

**Файли цього історичного релізу:** `LED-Lampa.apk`, `esp-release.zip`, `SHA256SUMS.txt`.
