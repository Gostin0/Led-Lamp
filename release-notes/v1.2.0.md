# 🌲 GOSTIN LED LAMP — Android v1.2.0 / ESP8266 v7.5.0-WEB-DEV1

**Історичний експериментальний реліз · 11 жовтня 2026**  
Перша опублікована версія цієї лінійки Android + ESP8266 із комплектом OTA.

## Що містить
- **Android v1.2.0** (`versionCode 1200`): керування ON/OFF, яскравістю, білим світлом, ефектами й кольорами.
- Підтримка джерел **ESP MIC / PHONE MIC / AUDIO CAPTURE**.
- SMART LIGHT: вечірній і нічний режими, реакція на звук, поріг чутливості, таймер тиші.
- Час, координати та розрахунок сутінків; чотири світлові будильники.
- Android-віджет, плитка швидкого доступу, перевірка оновлень через GitHub.
- **ESP8266 v7.5.0-WEB-DEV1:** тестовий Web UI з SMART LIGHT, налаштуваннями й логотипом GOSTIN.
