# 🌲 GOSTIN LED LAMP — Android v1.4.7 / ESP8266 v7.5.18

**Актуальний опублікований комплект** · Android, ESP8266, Web UI та OTA в єдиній системі.

Ця версія виправляє екран налаштування Wi-Fi на Android і додає новий **Forest Glass Web UI** до комплекту відновлення та OTA. Алгоритми ESP8266 залишаються на перевірюваній базі **7.5.18-BOOT-SCAN-RC1**.

## 📱 Android 1.4.7 — основні зміни

- **Wi-Fi-вікно:** адаптивний розмір, вертикальна прокрутка, читабельний темний фон і компактні розгортані секції замість довгого діалогу.
- **Робота з клавіатурою:** налаштування SSID і пароля та кнопка «Зберегти і перезавантажити» доступні на невеликому екрані.
- **BOOT SCAN:** список мереж завантажується з кешу ESP8266; кнопка «ЗНАЙТИ WI-FI» не виконує повторного сканування.
- **Forest Web в APK:** додано нові `index.html`, `app.js`, `style.css` та `forest.jpg`.
- **LittleFS-відновлення:** підтримано Web-фон і виправлено пріоритет застарілого локального комплекту над вбудованими в новий APK файлами. Ручний імпорт залишено.
- **Плитка у шторці:** при ввімкненні лампи обирає **White Light**, а якщо лампа вже ввімкнена — вимикає її.
- Збережені ESP MIC, PHONE MIC, AUDIO CAPTURE, музичні ефекти, SMART LIGHT, будильники, Wi-Fi OTA та Recovery.
- Android: `versionName 1.4.7`, `versionCode 1407`.

## 🔧 ESP8266 7.5.18-BOOT-SCAN-RC1

- Одне сканування Wi-Fi при кожному запуску; кеш до **12 мереж**.
- Wi-Fi Setup та Android лише читають уже збережений список SSID.
- Аудіоефекти, локальні HTTP/UDP API, SMART LIGHT, OTA й **Recovery на порту 81** збережені.
- Для оновлення переліку мереж потрібно **перезавантажити ESP8266**.

## 🌲 Web UI та OTA

Комплект `esp-release.zip` складається з `firmware.bin`, `manifest.json`, **4 файлів Forest Web** (разом із `web/forest.jpg`) та **3 файлів Wi-Fi Setup**.

Загалом **7 файлів вебінтерфейсу**, а не шість, як у попередньому комплекті. Версія прошивки залишається **7.5.18**. Редизайн Web і вбудоване відновлення ще потребують подальших апаратних перевірок на ESP8266 з обмеженою RAM.
