# Історія змін — GOSTIN LED LAMP

## ESP8266 v7.5.15 / Android v1.3.0 — SMART LIGHT

**Релізний комплект опубліковано користувачем у GitHub Releases.** Підтвердження повного апаратного тестування саме цієї збірки ще очікується.

### SMART LIGHT
- Автоматичне вечірнє й нічне освітлення за звуком A0.
- Колірна температура 1800–6500 K окремо для вечора, ночі та чотирьох будильників.
- Геолокація, сонячні події, місцевий час і DST.
- SMART ANIMATION: іскорки, заповнення лампи знизу, 60-секундне згасання згори.
- SMART REWIND: повторний звук розвертає згасання з поточного стану.
- Години тиші з підтримкою інтервалу через північ. Вони блокують запуск **лише з повного OFF**. Активний звуковий цикл продовжує реагувати до повного згасання.
- Чотири незалежні світлові будильники; прибрано сервісну кнопку тесту будильника.

### Web UI та Android
- Перегруповано інтерфейс автоматичного освітлення.
- Винесено службові налаштування анімації під шестерню.
- Узгоджено параметри SMART LIGHT у Web та Android.
- Залишено сумісність із попередніми конфігураціями та поточними API.

### Що перевірити на пристрої
- Розклад годин тиші, реверс та роботу будильника на коректному локальному часі.
- Правильне збереження Kelvin після reboot та фізичний колір WS2812B.
- OTA, Android update, пам'ять ESP8266 та стабільність під навантаженням.
